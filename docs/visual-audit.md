Rules:

- Product pages use official merchant imagery when available.
- If no exact product photo is available, the UI falls back to a neutral labelled panel, never another product.
- Digital services avoid invented screenshots and use text-led editorial treatment.
- Guide covers use the same editorial photography system as the home page.
